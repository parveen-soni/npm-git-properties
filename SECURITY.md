# Security Policy

## Supported Versions

Only the latest major and minor releases of `npm-git-properties` receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| < 2.0.0 | :x:                |

## Reporting a Vulnerability

The maintainers take security seriously. If you discover a security vulnerability in `npm-git-properties`, please report it privately:

1. **Do NOT open a public GitHub issue.**
2. Send an email to the repository maintainer at **thelastestcomputing@gmail.com**.
3. Please include:
   - A detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept (PoC).
   - Potential impact and recommended mitigations, if known.

### What to Expect

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will coordinate with you to validate the issue and prepare a fix.
- A public security advisory will be published upon releasing the patched version.

### Zero-Dependency Principle

`npm-git-properties` strictly adheres to a **zero external runtime dependencies** architecture to ensure that downstream projects remain insulated from third-party supply-chain attacks.
